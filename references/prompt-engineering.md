# 中文文生图Prompt写作指南（2026年5月更新）

## 适用范围

以下Prompt写法适用于支持中文的主流文生图模型：
- ChatGPT image generation (image2)
- NanoBanana
- zimage 系列

## 一、核心原则

### 原则1：正面描述 > 负面排除

用正面描述定义想要的效果，不通过列举不想要的来控制风格。

```
✅ 想要写实：从正面写"电影级写实摄影，35mm胶片质感，自然光"
❌ 错误做法："禁止动画风格、禁止CGI、禁止手绘"

✅ 想要都市夜景：从正面写"路灯照亮湿润路面，零星车辆行驶，暖黄窗灯"
❌ 错误做法："禁止末日风、禁止空城氛围"
```

如果某天你要做末日风MV，正面写成"废墟城市，破碎建筑，灰烬飘落天空"——prompt是通用的，风格随需求变。

### 原则2：摄影记者式描述

用具体摄影术语，不用抽象形容词。

```
✅ "85mm长焦镜头，浅景深，侧逆光照亮面部，自然肤色纹理可见"
❌ "一张美丽的照片，色彩鲜艳，非常震撼"
```

### 原则3：五段式结构（ChatGPT Image 2推荐）

```
[场景/环境] → [主体+特征] → [关键细节] → [构图/光线] → [正面约束]
```

示例：
```
夜晚雨中城市全景俯拍。高层住宅楼亮着零星暖黄窗灯。路灯照亮湿润路面，
地面反光形成镜面。前中后景层次分明由近及远。电影级摄影质感。
```

### 原则4：优先描述3个最重要特征

不堆砌10个细节。过长prompt导致模型注意力分散。

### 原则5：利用模型常识

常见场景不赘述。"咖啡店""大学校园""公交车站"——模型已经知道这些。

## 二、Prompt结构：五段式详解

| 段位 | 作用 | 长度 | 示例 |
|------|------|------|------|
| 场景 | 环境+构图 | 1句 | "俯拍夜晚雨中城市全景" |
| 主体 | 核心人物/物体 | 1-2句 | "一个25岁男性坐电脑前，黑短发银框眼镜" |
| 细节 | 关键材质/纹理 | 1句 | "屏幕冷白光从正面照亮面部，键盘区域" |
| 光线 | 光源+方向+色调 | 1句 | "窗外黑蓝夜景虚化，室内冷灰调" |
| 约束 | 正面描述+画质 | 1句 | "电影级摄影质感，35mm胶片颗粒" |

## 三、负面Prompt的正确用法

### 只排除技术瑕疵，不排除风格

```
正确的负面Prompt（通用）：
模糊、变形的手指

错误的负面Prompt（会卡死其他风格）：
动画、卡通、手绘、CGI、3D渲染、塑料感、末日风、空城氛围
```

为什么"禁止动画"是错的？——以后你要做动画MV时，prompt自己打了自己的脸。

### 风格从正面控制

| 想要的效果 | 正面描述 | 
|-----------|---------|
| 写实摄影 | 电影级写实摄影，35mm胶片质感，自然光照明 |
| 新海诚动画 | 新海诚动画电影风格，细腻光影渲染，柔和色彩过渡 |
| 末日废土 | 荒废城市全景，破碎建筑，灰黄天空，金属锈蚀 |
| 赛博朋克 | 霓虹灯街道，全息广告牌，雨夜都市，蓝紫冷调 |

## 四、常见Prompt改写

### 错误：堆砌+负面排除

```
电影级写实画面，35mm胶片质感，8K超清画质。俯拍夜晚雨中的城市全景，
数十栋高楼建筑，其中约七八扇窗户亮着暖黄灯光，所有建筑玻璃幕墙上有
雨水向下流淌形成竖条纹。地面街道全黑无人，远处一串白色和红色车灯
形成细长光带。整体蓝色偏灰冷色调
```

问题：细节过多（数十栋、七八扇、所有建筑），"全黑无人"触发末日联想，色调单一。

### 正确：层次分明+正面描述

```
夜晚雨中城市全景俯拍。高层住宅楼亮着零星几扇暖黄窗灯。路灯照亮
湿润路面形成长条反光。远处车流畅行尾灯拖出红白光影。蓝黑天空，
暖色窗灯和冷色街灯形成对比。电影级写实摄影，35mm胶片质感。
```

## 五、角色资产图Prompt模板

横版三视图格式：左侧半身肖像 + 右侧全身正/侧/背三视图。

```
电影级写实摄影，自然光照明。一张横向排列的人物设定参考图，
纯白背景柔光。

左侧（占画面40%）：[姓名]正面半身肖像。[发型/脸型/五官/服装详细描述]。

右侧（占画面60%）：同一人物全身三视图从左到右排列——
正面全身站立、左侧面全身、背面全身展示后脑和背部。
全身穿着：[服装描述]。身材：[描述]。
```

## 六、情绪→视觉对照表

| 情绪 | 正面视觉描述 |
|------|------------|
| 孤独 | 单个人物在空旷室内，窗外雨夜，冷蓝灰调 |
| 温暖 | 暖金色逆光，微笑特写，柔焦过渡 |
| 压抑 | 低照度单光源，人物在暗处，构图紧凑 |
| 释然 | 云层裂开透光，人物从暗处走出，暖色渐亮 |
| 遗憾 | 褪色冷色调，空椅子，雨中窗外，低饱和 |

## 七、场景光照尾缀速查表

Prompt末尾的光照描述比画幅/质感描述更能塑造氛围。不能所有镜头共用一个前缀。

| 场景类型 | Prompt末尾光照尾缀 |
|----------|------------------|
| 都市夜晚（室外） | 日常纪实摄影，生活感都市夜光 |
| 室内夜晚 | 日常纪实摄影，生活感室内夜光 |
| 室内白天 | 日常纪实摄影，生活感室内自然光 |
| 暖调室内（餐厅、咖啡馆） | 日常纪实摄影，暖调室内生活光 |
| 冷调室内（浴室、办公室） | 日常纪实摄影，冷白荧光灯室内光 |
| 室外白天（校园、街道） | 日常纪实摄影，温暖午后自然光 |
| 月光夜景 | 日常纪实摄影，月光室内光 |
| 教堂室内 | 日常纪实摄影，柔和教堂自然光 |
| 暗房 | 暗房纪实摄影，红色安全灯光照 |
| 剧场舞台 | 日常纪实摄影，戏剧舞台灯光 |
| 屏幕/手机界面 | 日常纪实摄影，屏幕光特写 |
| 城市全景鸟瞰 | 日常纪实摄影，[天气]都市鸟瞰 |

**关键认知**："电影级写实""35mm胶片"等宏大前缀会赋予画面史诗/科幻气质，不适合日常叙事MV。日常题材用"日常纪实摄影 + 精确光照环境"更贴切。光线的描述比质感描述更能塑造氛围。
